# Documentation Directory

← [Back to Main README](../README.md)

This directory contains detailed guides and documentation for various aspects of using VSCodium for academic writing, research, and development.

## Overview

The documentation is organized into topic-specific guides that cover everything from initial setup to advanced workflows. Each guide is designed to be comprehensive yet accessible, with step-by-step instructions and practical examples.

## Documentation Guides

### Core Setup & Configuration

#### [Terminal Guide](terminal.md)
Introduction to using the terminal (command line) on different operating systems:
- Opening the terminal on macOS, Windows, and Linux
- Basic terminal commands and navigation
- VSCodium's integrated terminal
- File operations and common tasks
- Essential tips and troubleshooting

**Start here if**: You're new to using the command line or need a refresher on terminal basics. Many other guides assume familiarity with the terminal.

#### [LaTeX Guide](latex.md)
Complete setup and configuration for LaTeX document preparation, including:
- Installation instructions for macOS, Windows, and Linux
- Setting up the `texmf` directory for global LaTeX resources
- Configuring `.latexmkrc` for automated builds and clean project organization
- LaTeX Workshop extension configuration
- Troubleshooting common LaTeX issues

**Start here if**: You want to write academic papers, dissertations, or any documents requiring professional typesetting.

#### [Git Workflow](git.md)
Version control and collaboration using Git, covering:
- Forking and cloning this repository to maintain your configuration
- Using Git within VSCodium (GUI workflow)
- Git CLI basics for advanced users
- Collaborating on projects with others
- Integrating with Overleaf for collaborative LaTeX editing
- Setting up SSH keys for secure authentication
- Creating and managing pull requests

**Start here if**: You want to backup your configuration, track changes to your projects, or collaborate with others.

### Extensions & Tools

#### [Claude Code Installation Guide](claude-code.md)
Installing and configuring the Claude Code AI coding assistant, including:
- CLI installation for macOS, Windows, and Linux (Ubuntu, Arch, NixOS)
- VS Codium extension installation from Open VSX
- Configuration options (subscription plans vs. API keys)
- Verification and troubleshooting
- Platform-specific installation methods

**Start here if**: You want AI-powered coding assistance directly in your editor.

#### [Zotero Integration](zotero.md)
Connect your reference manager with VSCodium for seamless citation management:
- Installing and configuring Zotero
- Better BibTeX plugin setup
- Exporting your library for use with LaTeX
- Citing references in your documents
- Keeping citations synchronized

**Start here if**: You need to manage bibliographies and citations for academic writing.

#### [Tools Reference](tools.md)
Comprehensive guide to additional tools and workflows, covering:
- **Markdown**: Writing and previewing Markdown documents
- **Templates**: Using LaTeX templates for consistent document structure
- **Snippets**: Creating reusable code fragments to speed up writing
- **Pandoc**: Converting between document formats (Markdown, LaTeX, Word, etc.)
- **Python**: Setting up Python development environment
- **Jupyter Notebooks**: Interactive computing and data visualization
- **Folder Templates**: Organizing project structures

**Start here if**: You want to explore the full range of VSCodium's capabilities for academic work.

#### [Jupyter Notebooks](jupyter.md)
Interactive computing environment for data science and research:
- Setting up Jupyter in VSCodium
- Creating and running notebooks
- Data visualization
- Integration with Python and other kernels
- Exporting notebooks to various formats

**Start here if**: You work with data analysis, scientific computing, or computational research.

## Getting Help

If you encounter issues or have questions:

1. **Search the documentation**: Use your browser's search function to find relevant topics
2. **Check the specific guide**: Each guide has troubleshooting sections
3. **Review closed issues**: Your question may have been answered on [GitHub Issues](https://github.com/benbrastmckie/VSCodium/issues?q=is%3Aissue)
4. **Open a new issue**: If you can't find an answer, [create a new issue](https://github.com/benbrastmckie/VSCodium/issues/new)
5. **Contribute**: Found a solution? Submit a pull request to help others

## Contributing to Documentation

We welcome contributions to improve this documentation:

1. Fork the repository
2. Make your changes in the `docs/` directory
3. Ensure your changes are clear and well-formatted
4. Test any instructions you provide
5. Submit a pull request with a description of your improvements

### Documentation Standards

When contributing to these guides:

- Use clear, concise language
- Provide step-by-step instructions where appropriate
- Include code examples and screenshots when helpful
- Organize content with clear headings
- Test all commands and procedures
- Link to related documentation
- Update this README if adding new guides
